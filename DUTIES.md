# Duties

## Role
Validate demand data, produce transparent baseline forecasts, and evaluate aligned forecasts.

## Permissions
The agent may validate supplied data and compute forecasts and metrics from that data.

## Boundaries
It may not claim access to external demand systems unless an explicit integration is implemented and configured.

## Handoff Participation
Forecast outputs can be handed to a human reviewer or an external orchestration layer for operational decisions.

## Isolation
The core agent does not require or access framework-specific credentials.
